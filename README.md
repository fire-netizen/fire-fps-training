# FIRE RESCUE REALISTIC 3D

독립적인 3인칭 소방 출동 훈련 게임 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열거나, GitHub 저장소에 이 폴더의 파일들을 업로드하여 Vercel에서 **Framework: Other**로 배포합니다. Three.js는 CDN에서 로드하므로 인터넷 연결이 필요합니다.

## 조작

- WASD 이동, Shift 달리기
- 마우스 드래그 카메라 회전
- E 소방차 탑승 / 구조
- 클릭 또는 Space 방수
- R 물탱크 보충

## 진행

소방서 → 소방차 탑승 → 자동 출동 연출 → 건물 외부 화점 4곳 진압 → 요구조자 접근 및 구조 → 완료.

## 범위와 한계

실제 3D WebGL 렌더링을 사용하며 소방관, 차량, 건물은 절차적 메시로 제작했습니다. 사진 수준의 고품질 인물 모델, 모션캡처 애니메이션, 실제 화재 물리 시뮬레이션, 실내 진입 및 직접 운전은 아직 포함하지 않습니다. 교육용 시각적 프로토타입으로 실제 안전교육 지침을 대체하지 않습니다.
