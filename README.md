# 119 FIRE HERO — 소방관 미션 RPG

실제 사람 소방관 캐릭터(방화복·헬멧·공기호흡기)를 조작해 출동 → 현장 임무 → 퀴즈 → 계급 승진으로 이어지는 소방안전 교육용 3D 롤플레잉 게임입니다. (Vite + three.js)

## 실행
```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # dist/ 빌드 (Vercel 배포용)
```
Vercel: GitHub 저장소 연결 → Framework **Vite** 선택 → 그대로 Deploy.

## 조작
| 키 | 동작 |
|---|---|
| W A S D / Shift / C | 이동 / 달리기 / 자세 낮춤 |
| 마우스 | 시점·조준 (화면 클릭 시 마우스 고정) |
| 클릭 · Space | 방수 / 소화기 분사 |
| Q | 직사 ↔ 분무 |
| E | 상호작용 (길게 누르는 항목 있음) |
| 1 / 2 / T | 관창 / 소화기 / 열화상 카메라 (5번 임무에서는 1~6 = 소화약제 선택) |
| M / Esc | 소리 / 일시정지 |

## 임무 (권장 진행 순서)
1. **출동 준비** — 보호장비 착용 순서, 버디 체크
2. **소화약제 선택 실습** — 나무·휘발유·배전반·나트륨·식용유·리튬이온 배터리 6가지 화재에 약제 6종(물·분말·CO₂·포·팽창질석/모래·K급) 중 알맞은 것을 선택. 잘못 고르면 확대·감전·폭발(나트륨+물)
3. **초기 소화** — A/B/C 화재 유형별 소화수단, 소화기 PASS, 물 오용 감점
4. **주택 화재 외부 진압** — 호스 전개, 화점 뿌리 조준, 용수 관리, 붕괴 위험구역
5. **연기 속 인명검색·구조** — 낮은 자세, 문 개방(백드래프트), 공기 관리, 열화상, 요구조자 이송

각 임무 후 상황판단 퀴즈 3문항 → 점수·별·경험치 → 계급(소방사→소방령) 승진. 진행은 브라우저(localStorage)에 저장됩니다.

## 폴더 구조
- `src/main.js` 게임 루프(출동 연출·상호작용·결과 흐름)
- `src/character/human.js` 소방관 캐릭터(장비 색상 `GEAR_COLORS`)
- `src/missions/` 임무 5개 (5번의 화재별 약제 적응성 표는 `m5-agents.js`의 `RULES`, 약제 목록은 `src/data/agents.js`) · `src/data/quizzes.js` 퀴즈(정답은 항상 첫 번째 보기, 실행 시 섞임)
- `src/data/progress.js` 계급·경험치 · `src/world/` 맵·불·물·호스 · `src/ui/` HUD·모달
